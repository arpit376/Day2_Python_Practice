DAY 2 WARM-UP: PYTHON PRACTICE SCRIPTS
Run each from this folder:  python 01_read_log.py   (Python 3.8+)
Only 05 needs `pip install requests`; 07 needs `pip install pandas matplotlib` (optional).

01 read_log          Read a log file, count lines
02 regex_attach      Extract IMSI, message and time with regex
03 kpi_calc          Attach success rate, mean and p95 setup time
04 subprocess_basics Run commands, return codes, timeouts
05 api_call          Provision a subscriber over REST (local fake API)
06 try_finally_test  A mini test with pass/fail paths and cleanup
07 pandas_summary    Same KPIs in pandas, plus a plot (optional)

Each script ends with a "TRY" line: a small change for you to make.
